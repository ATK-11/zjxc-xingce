判断推理 · 套路速查

四套真题里判断错 71 道，是最大失分块（逻辑判断正确率仅 47.5%、定义 50%）。这张页把讲义的判定规则压成「何时用 → 怎么判」，页码是讲义原书页码，可回查原书例题。复盘时：先按题型找到卡 → 对着自己的错因看是哪一步没做 → 再用 07 页的分步解法对答案。

类比推理 定义判断 逻辑判断 图形推理

一、类比推理 《判断推理-理论+刷题》p4–p28

总策略：按考点对号入座，不要造句p4
何时用 任何类比题的第一反应
先在脑子里过考点清单（概念间 / 言语 / 经验常识 / 科学常识），再选答案；
凭「读着顺」造的句子往往是错项
概念间关系 · 全同p5
何时用 两个词说的是同一个东西
华夏＝轩辕，勺子＝调羹，杭州＝武林（旧称）；只要「完全同指」就是全同
概念间关系 · 并列p5
何时用 两个词同级、不重叠
矛盾关系：非此即彼（生 / 死、男 / 女）
反对关系：还有第三种（红 / 蓝，还有黄）
题干给矛盾，选项必给矛盾 —— 这是最常见的挖坑点
概念间关系 · 包含p5
何时用 一个词是另一个的一部分或一类
组成关系：A 是 B 的一部分（轮胎 : 汽车）
种属关系：A 是 B 的一种（苹果 : 水果）
问「组成还是种属」时，用「A 是 B 的一种」去试，通顺＝种属
言语关系 · 本义转义 / 一字多义p13
何时用 词义类考题
三字俗语（走后门、炒鱿鱼）、比喻象征（鸽子 : 和平）、本义→引申义；看是否由「实」变「虚」
言语关系 · 近义 / 反义p13
何时用 两个词意思近或相反
近义要区分程度与用法（请求 vs 恳求）；反义常在成语间考（一蹴而就 vs 循序渐进）
经验常识 · 功能 / 配套p18
何时用 一个东西用来干什么、两个东西配套用
功能关系（剪刀 : 裁剪）；配套关系是互补品 —— 一个涨价另一个需求也降（牙膏 : 牙刷）
经验常识 · 位置 / 属性 / 职业p18
何时用 空间关系、性质、人物与工作
位置（上 : 下、头 : 脚）；属性（盐 : 咸，形容词或「…性」）；职业（医生 : 手术刀）
经验常识 · 材料工艺 / 顺承 / 因果 / 条件p18
何时用 制作过程、先后顺序、因果链
材料工艺（木材 : 家具，需加工）；顺承（新月→满月→残月，下单→送货→签收）
因果（噪声 : 听力衰弱）；条件（下雨 : 地湿）
科学常识 · 十大公式p26
何时用 出现物理量、单位换算
速度＝路程÷时间；密度＝质量÷体积；重力＝质量×g；压强＝压力÷受力面积
功＝力×距离；功率＝功÷时间；欧姆定律 I＝U/R；电功＝电功率×时间；电功率＝电压×电流；浓度＝溶质÷溶液
科学常识 · 七大国际单位p26
何时用 问「单位是什么」
米 m、千克 kg、秒 s、安培 A、开尔文 K、摩尔 mol、坎德拉 cd

二、定义判断 p29–p55 / 专项 p194–p197

定义判断四步走p30
何时用 任何定义题，尤其长定义
① 看清设问句式，圈出否定字词（不属于 / 未体现 / 除外）
② 关注被定义项本身，先猜它大概指什么
③ 细读原文释义，提炼核心要素
④ 逐项比对，正误一次筛掉
关键词标志 · 主体 / 客体p30
何时用 定义里出现「谁对谁做」
主体：数量、种类、性质（≥2 人、企业、行政机关）
客体：针对 / 面向 / 面对 / 对于 —— 抓「对象是谁」
关键词标志 · 方式 / 结果 / 条件p30
何时用 定义里出现手段、后果、前提
方式：利用 / 通过 / 以 / 借助
结果：使 / 导致 / 形成 / 从而
条件：「在…情况下」「当…时」
关键词标志 · 补充说明p30
何时用 定义后跟举例、并列、冒号
标志：如 / 例如 / 顿号并列 / 冒号 / 包括 —— 这些内容同样是判定要件，别跳过
多定义题：抓定义之间的差异p47
何时用 题干一次给两三个定义，问其中某一个
先看问的是哪个定义，再只比这几个定义的分歧点（比如「内隐记忆」与「外显记忆」的差别就在有无意识参与），用差异点排除选项
效应类定义（专项）p194
何时用 回归效应、凯伊效应、印随效应、疤痕效应…
效应类名字都唬人，但定义里必给产生条件 + 表现结果；把「条件」和「表现」拆成两条，选项只要缺一条就是错
言语类定义（诗句/文言论）p197
何时用 选项是古诗、成语、文言论断
先翻译选项的字面意思，再对定义要件；不要去猜诗人的情感，只比对「谁 + 做了什么 + 结果」
选非题（不属于 / 未体现）p30
何时用 设问带「不」
动笔前先圈「不」、在题干旁画 ×；四个选项里三个符合，剩下的就是答案 —— 别按选是题的习惯抢答

三、逻辑判断（四卷错 21/40，最该补） p56–p134

翻译推理 · 前推后p57
何时用 出现「如果…那么…」「只要…就…」「所有…都…」
前推后标志词：如果 / 若 / 只要 / 则 / 那么 / 就 / 会 / 所有 / 都 / 必须
写成 A → B
翻译推理 · 后推前p57
何时用 出现「只有…才…」「不…不…」
后推前标志词：只有 / 才 / 不A不B（＝A→B）
「只有 A 才 B」→ B → A；「不 A 不 B」→ B → A
翻译推理 · 除非…否则…p57
何时用 出现「除非 A，否则 B」
去掉关联词，否一推一：¬A → B（默认否前推后）
理解法：谁更重要谁放后面；实在绕就代真值试
翻译推理 · 逆否等价 / 肯前肯后p57
何时用 已经推出一个 A → B，判断选项能不能推
逆否命题与原命题等价：A→B ⇔ ¬B→¬A
肯前必肯后，否后必否前；否前肯后都不确定（这是最高频错项）
集合推理 · 文氏图法p67
何时用 问「能推出什么」，出现「所有 / 有的」
结论型优先画文氏图：先画全量关系（所有），再画部分关系（有的）；位置难定的用虚线相连，「有的」可双向
集合推理 · 三段论口诀p67
何时用 给两个前提求结论（前提型）
三概念各出现两遍；中项出现要全覆盖；前提有否，结论必否；前提有特（有的），结论必特；两否无结论、两特无结论
真假推理 · 矛盾剩余法p73
何时用 几个人说话，只有一真/一假
① 找矛盾（a 是 b ↔ a 不是 b；A→B ↔ A 且 ¬B）—— 矛盾必一真一假
② 看剩余句子的真假
③ 有必要时把假命题变真（取反）再推
真假推理 · 反对剩余法p73
何时用 「有的 S 是 P」与「有的 S 不是 P」同现
上反对关系：两句不能同假，必有一真；据此先锁定真话位置，再看其余
排列组合 · 选项代入法p77
何时用 选项把所有人的位置/属性都列全了
从确定信息最多的选项开始代，一代就验证全部条件，比硬推快
排列组合 · 直推 + 列表连线p77
何时用 选项只问某一项，条件零散
以确定信息和出现次数最多（最大信息）为切入点；画表格或连线，边推边划掉不可能
削弱论证 · 先找论点p89
何时用 任何削弱/加强题的第一步
论点关键词：认为 / 觉得 / 推测 / 断言 / 因此 / 所以 / 由此可见 / 据此认为
有发声主体（专家说、研究发现）就抓主体；论点多在尾句
削弱论证 · 削弱论点三法p89
何时用 要找「最能削弱」
① 直接削弱：与论点正面相反
② 补充新理由：道理论证（讲机制）、举例（摆反例）、对比（有它没它）
③ 力度比较：直接 > 间接；必然 > 可能；本质 > 现象；量大 > 量小
加强论证 · 补新理由p103
何时用 要找「最能加强」
直接重复论点几乎不考；给新证据（举例、讲原理、对比）才是强化；注意「加强」≠「同义反复」
前提加强 · 搭桥抓新概念p116
何时用 题干论据与论点之间缺一环
论据有 A、论点有 B，而 A 与 B 之间没连线 → 答案必是「A → B」的桥；找不到桥就找必要条件
前提加强 · 必要条件（反向代入）p116
何时用 问「必须假设/前提是」
把选项取反，代回题干：题干结论崩了＝它就是必要条件；取反后结论仍成立 → 不是前提
评价论证p122
何时用 问「答案最能评价结论」「关键问题是什么」
借必要条件思维：这个问题的两种回答，会让结论一个成立一个不成立 → 就是答案
原因解释 · 转折词找矛盾点p123
何时用 问「最能解释上述现象」
先在题干里找转折词（但是 / 然而 / 却 / 结果），转折前后的反差就是矛盾点；答案要能同时兼容两边
原因解释 · 不否题干实情p123
何时用 选项看着很合理
坚守客观：不能否定题干已经给出的事实；只解释「为什么」，不改写「是什么」
相似结构 · 重形轻义p126
何时用 问「与上述推理结构最为类似」
只看句式骨架，不管内容：① 三段论——标字母（重点看首句后半）、找「朋友」、定方位配对，兼顾范围与是非
② 因果——辨因果、分先后
③ 条件——写成 A→B、A 或 B 再对号
日常结论 · 六类错误选项p132
何时用 问「由此可以推出」
① 绝对化（一定/必须/所有/唯一/完全/凡是）② 无中生有 ③ 偷换概念 ④ 强加比较 ⑤ 过度推断 ⑥ 时态混淆（已经/将要）

四、图形推理 p135–p204

图形推理总扫查顺序（30 秒定方向）p135
何时用 看到图推第一眼
① 组成相同 → 位置类（平移/旋转/翻转）
② 组成相似 → 样式类（加减同异/黑白运算）
③ 组成不同 → 先属性（对称/曲直/开闭），后数量（面→线→点→角→素）
④ 都不像 → 特殊类（图间关系/拼合）
位置类 · 平移三要素p136
何时用 元素构成相同，只是位置变了
看平移的区域（整行/整列/环形/内外圈）、方向（顺逆时针、上下左右）、步数（恒定、等差、循环）
位置类 · 旋转与翻转p136
何时用 图形朝向变了
旋转看方向 + 角度（45°/90°/180°）；翻转是镜像 —— 左右翻、上下翻，不能靠旋转得到；拿一个不对称的角当锚点判断
样式类 · 加减同异p142
何时用 图形相似但细节有增减
求同（只留共同部分）、求异（只留不同部分）；常与旋转/翻转叠加考 —— 先转再算
样式类 · 黑白运算p142
何时用 框架完全一致，只有黑白不同
从已知图相同位置推出四组公式：黑+黑、白+白、黑+白、白+黑；顺序不能颠倒（黑+白 ≠ 白+黑）；每题规则都不同，不能背
样式类 · 黑白运算秒杀p142
何时用 九宫格黑白、算得慢
① 找成片区域（一大块同色，一眼定一组公式）② 穷尽一种颜色（先把黑+黑、黑+白 全推完，剩下自然确定）
属性类 · 对称性p149
何时用 图形规整、有轴
类型（轴对称/中心对称/既轴又中心）；再看轴的数量、方向、夹角、是否重合、与点线面素的关系；对称常是分类题的分组依据
属性类 · 曲直性 / 开闭性p149
何时用 图形是线条或封闭区域
曲直：全直 / 全曲 / 曲直混合，还可与位置叠加
开闭：全封闭 / 全开放 / 半开半闭；有开口就优先数开口方向
数量类 · 面p156
何时用 图形被切割成很多块
特征图：四边形被切割、数字/汉字、生活化图标、三角形、麻将桌
数：无差别面数 → 相同面 → 最大/最小面 → 三角形/四边形个数 → 面积大小
数量类 · 线p156
何时用 单一长线、多边形、圆、字母汉字
数：总线条数 → 直线/曲线 → 内线/外框线 → 平行线 → 一笔画
数量类 · 一笔画判定p156
何时用 图形能一笔画成 / 问笔画数
奇点判定法：奇点＝0 或 2 → 一笔画；奇点数 > 2 → 笔画数＝奇点数 ÷ 2
数量类 · 点 / 角 / 素p155
何时用 线交叉多、有尖角、小元素多
点：交点、切点、端点、十字交叉点
角：锐角/直角/钝角个数，直角优先
素：小元素个数、种类、部分数；遍历——缺啥补啥（元素/颜色/位置遍历）
特殊类 · 图间关系p170
何时用 多个小图形摆在一起
位置（上下左右/中心/边缘）、相邻或相隔、相邻或相对、相接/相交/相离/相含/相压、点接或线接
特殊类 · 平面拼合p170
何时用 给几个零散小块拼成大图
① 锁定特殊边：最长边、斜边、凹凸边当基准
② 平行等长消边：拼合后重合的边抵消，只看外轮廓
立体类 · 拆折纸盒（通用解法）p179
何时用 六面体展开图折成盒子
① 选基准面 ② 比对它的右面 + 顶面，不符就换下一项 ③ 相邻面没直接给出时用滚动法，靠 L 型两侧共边判定
立体类 · 公共点法p179
何时用 要滚 2 次以上、卷面乱
① 取 L 型结构的公共顶点为 1，L 两端标 2 ② 若 2 是完全公共点（在 3 个面上），顺/逆时针续标 3 ③ 遇到非完全公共点就停，换另一个 L 型重新开始
立体类 · 视图 / 截面p180
何时用 三视图、切一刀
视图：分清主/俯/左/右/后/仰六个视角，比轮廓形状再查细节差异
截面：先看能不能切出斜边、圆弧，再看面数上限
黑白类专项（十三考点）p203
何时用 黑白球、黑白块
数量（黑/白块数）→ 位置（平移旋转翻转）→ 叠加（黑+黑等四种）→ 对称性 → 部分数 → 笔画数 → 线条数 → 分割区域 → 面积占比 → 周长 → 相连方式（点连/线连）→ 两两比较 → 黑白接壤
判断做题时间分配（本模块专用）—
何时用 整卷时
定义 8 题 8 分钟；类比 10 题 6 分钟；逻辑判断 14 题 16 分钟；图推 6 题 5 分钟；卡住 40 秒就跳，全模块不超 38 分钟
