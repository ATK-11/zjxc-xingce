资料分析 · 公式速查 《2027 资料分析理论+刷题课》p3–p146

基期与现期p3 / p82
何时用 题干时间比材料靠前 → 求基期；比材料靠后 → 求现期
基期量 = 现期量 ÷ (1+增长率)
现期量 = 基期量 × (1+增长率)
同比与环比p3
何时用 同比：与历年同一时期比；环比：与紧邻的上一周期比
同比＝第一个时间单位前推一次，其余不变
环比＝最后一个时间单位前推一次，其余不变
百分数 vs 百分点p3
何时用 两个增长率/比重之间做比较、加减
增长率之间比较用「百分点」，直接相减即可
增长率p73 / p155
何时用 出现「比…增长/下降 x%」「增长几倍」「高几倍」
增长率 = 增长量 ÷ 基期量 = (现期−基期)÷基期 = 发展速度−1
增速 ≈ 增幅；只有「增幅多少」指增长量
增长量p102
何时用 出现「增长/减少 具体数值」，一般带单位
增长量 = 现期−基期 = 基期×r = 现期 × r/(1+r)
增长量速算（特殊分数）p102
何时用 r 是或接近 1/n（如 12.5%=1/8）
增长量 = 现期量 ÷ (n+1)
r 不是特殊分数 → 先算 r/(1+r) 或 现期/(1+r)，再相乘；选项极近 → 代选项反推
增长量比较p110
何时用 四个选项比「增量最大/最小」
① 现期大、r 也大 → 增长量大（大大则大）
② 一大一小 → 比「现期×r」
③ 乘积接近 → 回原公式精算（先看单位）
间隔增长率p89
何时用 时间点隔一期或差两期（2024 比 2022）
R = r₁ + r₂ + r₁×r₂
间隔基期 = 现期 ÷ (1+R)；间隔增长量 = 现期 × R/(1+R)；间隔发展速度 = 1+R
混合增速p92 / p155
何时用 材料里出现整体与各部分增速的关系（A+B=C）
① 整体增速居中（小于最大、大于最小）
② 整体偏向基期值最大的那部分
③ 选不出再用十字交叉
年均（平均）增长率p99
何时用 末期比初期的「平均」+「增长率」
末期 = 初期×(1+x)ⁿ，n = 末年份−初年份
n≤5 且 x≤5% 时：末期/初期 ≈ 1+nx，直接试算
平均增长量p107
何时用 末期比初期的「平均」+「增长量」
平均增长量 = (末期值 − 初期值) ÷ n
比重（现期）p117
何时用 「…占…%」「…在…中占」
比重 = 部分 ÷ 整体；整体 = 部分 ÷ 比重；部分 = 整体 × 比重
基期比重p124
何时用 题干时间靠前 + 求比重
基期比重 = (A/B) × (1+b%)/(1+a%)
A 部分现期量、a 部分增长率；B 整体现期量、b 整体增长率
比重变化（两期比重差）p127
何时用 问比重「上升/下降/不变」或变化几个百分点
a > b → 比重上升；a = b → 不变；a < b → 下降（a 部分增速，b 整体增速）
要具体几个百分点，需代公式算
混合比重p135
何时用 整体与各部分比重的比较
整体比重居中，且偏向部分值最大的那部分
平均数与倍数p137
何时用 「人均/单位面积/户均」「A 是 B 的几倍」
平均数 = 总数 ÷ 总份数；倍数 = A ÷ B
「均前每后」的量作分母；出现「年均/月均/日均」要除以对应时间
基期平均数（倍数）p139
何时用 时间靠前 + 求平均数或倍数
基期平均数 = (A/B) × (1+b%)/(1+a%)
平均值（比值）增长量p141
何时用 问「提高/降低了多少 元、件…」具体值
现期比值 − 基期比值（是具体数值，不是百分比）
比值（平均值）增长率p143
何时用 问「单价/单位面积产量 增长 x%」，答案一定是百分数
比值 r = (a% − b%) ÷ (1 + b%)
判趋势：a>b 上升，a<b 下降
乘积增长率p146
何时用 A = B×C，已知两个因子的增长率求乘积增长率
r_A = r_B + r_C + r_B×r_C（与间隔增长率同形）

资料分析 · 速算八法 p29–p69 / p148

先判选项差距（决定敢不敢估）p29 / p148
何时用 任何资料题动笔前
乘除：两个接近选项的倍数 ≥1.1 → 放心粗算；≈1.1 → 精准算；远小于 1.1 → 别估
加减：直接看选项差距与列式的关系
尾数法p32
何时用 精确计算，且只有 + − ×
只算最后一位或后两位，选项尾数不同才用；除法不建议用
削峰填谷法p148
何时用 一堆数求和 / 求平均
先定一个基准值，只算每个数与基准的差，再回加基准
首位直除法p39
何时用 除法、选项首位数字不同
分母四舍五入截前两位，只算商的第一位（首位相同就再算第二、三位）
特殊值法（分数化）p53
何时用 增长率是 1/n 附近的百分数
9.1%=1/11，10%=1/10，11.1%=1/9，12.5%=1/8，14.3%=1/7，16.7%=1/6，20%=1/5，25%=1/4，33.3%=1/3，50%=1/2
A×B(B→1/n)=A/n；A÷B(B→1/n)=A×n
画圈法（除化乘）p58
何时用 求基期且 r ≤ 10%（含基期差/和、基期比重、基期倍数）
基期 ≈ A×(1−r)（r≤5% 误差最小，误差率 r²）
做法：画个圈、变符号（下正上负、下负上正）→ 粗算 A×r → 用 A 加减
截位估算 / 拆分法p148
何时用 选项差距大 / 要求很精确
截位：分子分母各取「老大」，四舍五入留两位，其余按老大舍的位数截
拆分：把数拆成好算的两块相加
分数比较四招p61 / p148
何时用 比较两个分数大小（增长率、比重、平均数比较）
① 分数性质：钱多人少分数大（分子大且分母小 → 更大）
② 首位直除：先比数量级，同数量级比商的首位
③ 化同法：通分
④ 差分法：分子分母作差得差分数 → 小的和差分数比 → 用大的替换差分数

材料怎么读 p18–p27 / p69

文字材料p18
何时用 读材料时
多段落按「总-分」结构，标记每段第一个数据前的关键词当主旨词；时间点各不相同就直接标记时间
表格材料p22
何时用 读材料时
看「标题 + 横标目 + 纵标目 + 单位」四样，先确认单位和时间
图形材料p24
何时用 读材料时
看「标题 + 横轴 + 纵轴 + 图例 + 单位」；饼图从 12 点方向顺时针标记
综合材料 / 直接读数p26 / p69
何时用 读材料时
简单加减读数的题，验证顺序从 D 到 A；先查时间、主语、单位三个陷阱

数量关系 · 25 个方法 《数量关系-理论+刷题》p4–p87

代入排除法p4
何时用 选项是具体数字、列式复杂或带不定条件
把选项代回题干验条件，先从好算的选项代
数字特性法p6
何时用 出现比例、倍数、奇偶、尾数、整除字眼
用奇偶性/整除性/倍数关系直接排除选项
方程法p11
何时用 有等量关系、能设未知数
设未知数 → 列等式 → 解；复杂时设中间量
不定方程（组）p15
何时用 未知数多于方程个数，且要求整数解
用整除、奇偶、尾数、代入缩小范围
工程问题p18
何时用 出现「完成一项工程需要…天」「效率」
给定时间型：赋总量 = 时间的公倍数；给效率比型：直接设效率
行程问题p24
何时用 路程、速度、时间三者关系
普通行程 s=vt；相遇 s=(v₁+v₂)t；追及 s=(v₁−v₂)t；平均速度 = 总路程÷总时间（不是速度平均）
几何问题p32
何时用 周长、面积、体积、相似、三角形
套公式；不规则图形用割补/平移；相似比 k → 面积比 k²、体积比 k³
经济利润p46
何时用 成本、售价、利润、折扣、利润率
利润 = 售价−成本；利润率 = 利润÷成本；打折售价 = 原价×折扣；设成本为 100 最好算
容斥问题p53
何时用 「都参加」「只参加」「都不」
两集合：A+B−AB = 总数−都不
三集合标准：A+B+C−AB−AC−BC+ABC = 总数−都不
三集合非标准：只满足两个的、只满足一个的分开算
排列组合p57
何时用 「多少种安排/选法」，有顺序要求或分组
排列 A(n,m)=n!/(n−m)!；组合 C(n,m)；相邻用捆绑、不相邻用插空、相同元素用隔板
概率p65
何时用 「概率是多少」
古典概型 = 满足条件数 ÷ 总数；分步相乘、分类相加；对立事件 1−P
最值问题p69
何时用 「至少…才能保证」「最多/最少是多少」
最不利构造：最坏情况 +1
数列构造：设最大/最小为 x，其余按条件列不等式
年龄问题p71
何时用 年龄差不变
两人年龄差恒定；n 年后各加 n；用差不变列式或代入
溶液问题p73
何时用 浓度、溶质、溶液
浓度 = 溶质÷溶液；溶质守恒（加水/蒸发水时溶质不变）
星期日期问题p74
何时用 星期几、日期推算
平年 365=52×7+1（星期+1），闰年 +2；一个月内星期几出现次数看该月天数
统筹优化p75
何时用 「最少用多少时间/最少花多少钱」
排队打水：短作业优先；烙饼/加工：两两配对；最短路径：找最小生成树思路
数列问题p77
何时用 平均数、等差、等比
平均数 = 总和÷个数；等差：aₙ=a₁+(n−1)d，Sₙ=n(a₁+aₙ)/2；等比：aₙ=a₁qⁿ⁻¹
循环周期p79
何时用 「每隔几天」「第 n 个是什么」
先找周期长度 T，再看 n÷T 的余数；同时发生的题求最小公倍数
牛吃草p80
何时用 一边匀速消耗、一边匀速增长
设每头牛每天吃 1 份：原有草量 = (牛数−每天生长量)×天数，联立两组求生长量
比赛问题p82
何时用 单循环、淘汰赛、轮空、积分
单循环场次 = C(n,2)；淘汰赛决出冠军 = n−1 场；积分制先列胜平负方程
钟表问题p83
何时用 时针分针夹角、重合、成直角
分针每分钟 6°，时针每分钟 0.5°，速度差 5.5°/分；夹角 = |30H − 5.5M| 取小
植树问题p84
何时用 等距栽树、装路灯
两端都栽：棵数 = 段数+1；只栽一端 = 段数；环形 = 段数；段数 = 总长÷间距
方阵问题p85
何时用 正方形阵列、每边 n 个
实心方阵总数 = n²；最外层 = 4n−4；相邻两层差 8
天平问题p86
何时用 用天平最少称几次找次品
每次最多分 3 堆；n 次最多可分辨 3ⁿ 个（知道轻重）
杂题p87
何时用 空瓶换酒、拿牌、划船、剪绳
空瓶换酒：n 个空瓶换 1 瓶 → 相当于每瓶实付 (n−1)/n 价
拿牌：凑 (1+最大可取数) 的倍数
划船：注意返程要留人
剪绳：段数 = 剪的次数+1
