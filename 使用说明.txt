浙考行测训练场 · 使用说明（电脑离线版 + 安卓 v3.9）
================================================================

【一、这一版修了什么】
1) 中途退出不再“计时归零”（重点）
   以前：做到一半保存/关掉/切后台被杀，下次进来“已用时间”从 0 重新记，答题卡却还在。
   现在：每 10 秒自动存档，累计用时和每道题用时都会写进去；熄屏、切后台、直接杀进程都算得进去。
   自己验一下：做 5 分钟 → 按 Home 退出 → 再打开 → “已用”应该从 5 分钟接着走。

2) 新增「倒计」开关（题目卡右上，写着“倒计 关”）
   点一下切换档位：关 → 60 秒 → 90 秒 → 120 秒 → 关。
   开启后每题显示剩余秒数，超时变红显示负数，并且只提示一次“这题超了 N 秒，标记后先跳过”。
   建议：数量关系设 90 秒，其他模块 60 秒。这是治“一道题烧 9 分钟”的工具。

3) 补回两个之前安卓包里没有的功能
   · 学习模式的答题进度会跟着同步码走，换设备/重装能接上；
   · 交卷后解析里可以直接点「查公式 / 查套路 / 看导图」跳到对应学习页。

4) 首页恢复完整“学习资料”入口区（23 个入口），电脑版和安卓版内容一致。

【二、怎么打开】
电脑：解压后双击 index.html，用 Chrome / Edge 打开。不用联网、不用装服务。
安卓：装 浙考行测-v3.9.apk（覆盖安装保留记录；首次装要允许“未知来源”）。
      小米/红米平板：设置 → 应用设置 → 授权管理 → 安装未知应用 → 允许对应文件管理器。

【三、为什么能离线】
国考 + 浙江省考行测真题已内联在 assets/data/real/real-bundle.js，不通过网络读取；
申论模板、学习模式、思维导图、错题精讲全部在同一份安装包/文件夹里。

【四、自动同步（默认开启）】
- 已内置同步码，两端装好即互通；「同步」里可复制/粘贴同步码换设备。
- 同步内容：作答历史（含每题选了什么）、错题本、未交卷草稿、学习模式进度、打卡。
- 不同步：21 天日程的勾选状态。
- 走公开 MQTT 中转，免账号；没网照常做题，联网后自动补传。

【五、题库修正会自动下发】
题目/答案/解析的修正通过同步下发，不用重装；「同步」→「本机数据体检」里可看题库补丁版本。
只有改界面/图标才需要换新版本。

【六、记录存在哪】
存在浏览器/应用本地（localStorage），与文件夹位置无关。
Chrome 与 Edge 是两份互不相通的本地记录，绑同一个同步码后会自动合并。
清理浏览器数据 / 无痕模式会丢本地记录，重新打开并同步即可从云端拉回。

【七、常见问题】
Q：双击打开是空白？
A：用 Chrome / Edge 打开；个别国产壳浏览器禁止本地文件读取。安卓首次启动白屏等 3 秒（在建缓存）。

Q：图片显示不出来？
A：文件夹必须整体拷，不能只拷 index.html。

Q：同步一直显示「离线」？
A：检查网络；公司/学校网络可能封 8084 端口，换热点试试。

Q：公式图显示「（原卷公式图缺失）」？
A：少数题的公式图在公开数据源里本身就缺失，属源头问题。

Q：计时还是不准？
A：确认没开省电模式/后台限制；安卓上把本应用设为“不受限制”。

Q：发现题目答案/图片/解析有问题？
A：把题号发我（例如 zj-2021-A-q79），我直接改题库重打。
